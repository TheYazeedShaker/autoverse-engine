# Typography

Two self-hosted variable families: **Google Sans Flex** for Latin, **Cairo** for Arabic. Both load from
`@autoverse/tokens` (no CDN), split by `unicode-range` so each loads only for its script.

## Type scale

Sizes are tokens (`--av-text-*`), from `xs` to `4xl`.
